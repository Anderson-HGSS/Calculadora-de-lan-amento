# Calculadora-de-lançamento
Uma calculadora que calcula a altura de um objeto em relação ao chão, assim que ele é lançado.

O programa retorna tanto o gráfico da altura em relação ao tempo de simulação, quanto os dados e as informações mais exatas do objeto, que são exibidos no terminal.

Para utilizar, basta rodar o código e responder as perguntas solicitadas!
